# Телеметрия

**В этой сборке её нет.**

English version: [TELEMETRY.md](TELEMETRY.md)

Это **NoTrace Launcher** — форк [Millida Launcher](https://github.com/millida/launcher)
под GPL-3.0. Оригинальный лаунчер отправлял на `api.millida.net/v2/launcher/telemetry`
события о своей работе: запуски, вылеты, установки, клики, покупки — с постоянным
install id, — и отдельный пульс «в лобби / в игре» с сервером, на котором вы играете.
В этом форке всего этого нет.

Этот файл заменяет оригинальный `TELEMETRY.md`: что именно убрано, что по-прежнему
ходит в сеть и зачем, и как проверить это самому.

## Что убрано

| Было | Что делало | Стало |
|---|---|---|
| `src/lib/telemetry.ts` | очередь в `localStorage`, блок об устройстве (ОС, CPU, RAM, GPU, экран, локаль, часовой пояс, число сборок и модов), отправка пачкой раз в 2 минуты, при скрытии окна и на выходе, `app_start` / `app_exit` | модуль-заглушка: нет очереди, нет данных об устройстве, нет install id, нет таймера, нет HTTP-клиента |
| install id (`m-install-id`) | случайный UUID, склеивающий все события одной установки | не существует; `installId()` возвращает пустую строку, в `localStorage` ничего не пишется |
| `liveBeat` / `/launcher/heartbeat` | пульс раз в 40–50 с: install id, версия, сборка, версия игры и сервер | убран; запрос присутствия для друзей больше не несёт блок `telemetry` |
| `src/lib/crash.ts` → `/errors` | текст ошибки, стек и хвост лога игры, до 10 за запуск | только локально: ошибки держатся в памяти для текста диагностики |
| `src/lib/uiTrack.ts`, `uiClick.ts` | один слушатель на документ, превращавший каждый клик в `ui_click`, плюс `screen_view` и `impression` | удалены |

| `src/lib/compatSignal.ts` | голоса «этот набор модов упал» для графа совместимости | удалён |

| выключатель в `millida_mod.rs` | файл `telemetry-off` писался, только если игрок отказался | `game_telemetry_enabled()` жёстко возвращает `false`, файл пишется при каждом запуске |

## Мод в игре

Мод Millida по-прежнему ставится в сборки: он рисует скины, плащи и статус друзей
внутри игры. Его собственная статистика (сводка сессии на `/launcher/mod-telemetry`
раз в 15 минут) выключена наглухо, через оба выключателя, которые мод понимает:

- `MILLIDA_TELEMETRY=0` в окружении игрового процесса
  (`src-tauri/src/engine/game/launch.rs`);
- файл `telemetry-off` в папке данных лаунчера, пишется при старте
  (`engine/content/millida_mod.rs`, `arm_telemetry_off`).

В интерфейсе нет настройки, которая вернула бы это обратно.

## Что по-прежнему ходит в сеть

Без статистики лаунчер не стал офлайновым. Эти запросы — сами функции:

- **API Millida** (`api.millida.net`): каталог, вход, хостинг, друзья, скины,
  экономика. Без него каталог пустой.
- **Microsoft**: вход по OAuth для лицензии. Пароль вводится на странице Microsoft,
  не в лаунчере.
- **Modrinth, CurseForge, Mojang**: загрузка модов, модпаков и файлов игры.
- **Присутствие для друзей** (`/friends/presence/heartbeat`): только у вошедшего
  пользователя и только то, что друзья и так видят в списке — в лаунчере или в игре,
  сборка и сервер.
- **Мод в игре**: сервер, на который вы зашли, и сокет друзей — по той же причине.

Если не нужно и это, направьте сборку на свои сервисы: адреса лежат в
`src/lib/api.ts` и `src-tauri/tauri.conf.json`. `TRADEMARK.md` оригинального проекта
требует этого от любого распространяемого форка и так.

## Диагностика — локальная

«Скопировать диагностику» в настройках собирает текст: версия, железо, сборки,
Java, последние ошибки сессии и паники, которые ядро оставило на диске. Текст
собирается в окне и кладётся в буфер обмена — куда его отправить, решает игрок.
Ядро по-прежнему пишет заметки о паниках и зависаниях интерфейса в свою папку
падений; они попадают в этот текст и удаляются.

## Обновления выключены

Обновлятор смотрит на релизный канал Millida и доверяет её ключу подписи.
«Обновление» поставило бы поверх этой сборки официальную и вернуло статистику,
поэтому проверка отключена (`UPDATES_ENABLED` в `src/lib/updater.ts`). Включайте
её только вместе со своими адресами и своим публичным ключом в
`src-tauri/tauri.conf.json`.

## Как проверить

```bash
node scripts/check-no-telemetry.mjs
```

Скрипт входит в `npm run build:web`. Он валит сборку, если в исходники вернулся
эндпоинт, install id, ключ очереди или команда ядра, которая их кормила. Комментарии
перед проверкой вырезаются, поэтому этот файл его не роняет.

Чтобы посмотреть трафик — запустите лаунчер через mitmproxy: запросов на
`/v2/launcher/telemetry`, `/launcher/heartbeat`, `/errors` и `/v2/launcher/uninstall`
там нет.

## Что осталось от Millida

Код — GPL-3.0, бренд — нет. `TRADEMARK.md` оригинального проекта остаётся в дереве:
имя, логотип, иконки, плащ и дизайнерские изображения принадлежат Millida и здесь
заменены (форк обязан их менять). Арт каталога, фоны и маскот пока взяты из
оригинала — замените их, прежде чем публиковать сборку.
